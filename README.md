# TechWave — Podcast Landing Page

A fully responsive podcast landing page for **TechWave**, a daily podcast covering tech insights, productivity hacks, and personal growth for young professionals and tech enthusiasts.

## 🌐 Live URL

[https://responsive-wep-app.netlify.app/](https://responsive-wep-app.netlify.app/)

---

## 📌 Purpose

TechWave's landing page serves as the public face of the podcast. Its goal is to attract new listeners, showcase featured episodes, highlight the host's credentials, and direct visitors to their preferred streaming platform — all through a polished, mobile-friendly web experience.

---

## ✨ Key Features

- **Hero Section** — Bold introduction with tagline, a "Listen on Spotify" CTA, and a Subscribe button
- **Podcast Stats** — Key social proof displayed prominently: 150K monthly listeners, 200 episodes published, 4.9 average rating, and 50 industry experts featured
- **Why TechWave** — Five illustrated selling points: Premium Audio Quality, Mobile Friendly, Global Community (120+ countries), Exclusive Interviews, and Rich Resources
- **Featured Episodes** — Three embedded YouTube episodes with titles and runtimes:
  - *The Future of AI in Everyday Life* — 42 min
  - *Building Better Habits for Remote Work* — 35 min
  - *Career Growth in Tech: A Roadmap* — 51 min
- **Host Profile** — Bio for host Alex Kumar with links to LinkedIn, X, Instagram, and YouTube
- **Streaming Platform Links** — Footer CTAs for Spotify, Apple Podcasts, YouTube, and Twitter
- **Responsive Navigation** — Hamburger menu on mobile with smooth scroll links to About, Episodes, and Host sections
- **Mobile-First Design** — Layout adapts seamlessly across all screen sizes and devices

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **HTML5** | Page structure and semantic markup |
| **CSS3** | Styling, layout, and responsive design |
| **JavaScript** | Hamburger menu toggle and interactivity |
| **YouTube Embed API** | Embedded episode video players |
| **Tailwind css** | Faster styling, layout and easily responsive design |
| **Netlify** | Hosting and continuous deployment |
